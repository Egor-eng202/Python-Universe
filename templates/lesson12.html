Урок 12. Лямбда-функции и рекурсия

Теория

Лямбда — короткая анонимная функция.

square = lambda x: x * x
        print(square(4))   # 16

        nums = [3, 1, 2]
        nums.sort(key=lambda x: -x)
        print(nums)        # [3, 2, 1]

Рекурсия — функция вызывает саму себя. Нужен базовый случай выхода.

def fact(n):
            if n <= 1:
                return 1
            return n * fact(n - 1)

Задача

Отсортируйте список строк по длине с помощью лямбды.

Подсказка

Показать решение 
words = ["питон", "код", "программирование"]
        words.sort(key=lambda w: len(w))
        print(words)   # ['код', 'питон', 'программирование']
