Урок 8. Кортежи и множества

Теория

Кортеж — неизменяемая коллекция в круглых скобках.

point = (3, 5)
        x, y = point   # распаковка

Множество — уникальные элементы, без порядка.

s = {1, 2, 3, 2, 1}
        print(s)             # {1, 2, 3}
        s.add(4)
        s.discard(1)
        print(2 in s)        # True

Операции: объединение |, пересечение &, разность -.

Задача

Дан список с повторами — получите множество уникальных значений.

Подсказка

Показать решение 
data = [1, 2, 2, 3, 3, 3, 4]
        unique = set(data)
        print(unique)   # {1, 2, 3, 4}
