Урок 25. Финальный проект

Теория

Соберите всё вместе: создайте консольное приложение «Заметки» с сохранением в файл JSON.

  • Хранение заметок — список словарей.
  • Загрузка/сохранение — json.
  • Меню — while + input().
  • Обработка ошибок — try/except.

Задача

Напишите программу, которая добавляет заметки, показывает их и сохраняет в notes.json.

Подсказка

Показать решение 
import json

        FILE = "notes.json"

        def load():
            try:
                with open(FILE, "r", encoding="utf-8") as f:
                    return json.load(f)
            except FileNotFoundError:
                return []

        def save(notes):
            with open(FILE, "w", encoding="utf-8") as f:
                json.dump(notes, f, ensure_ascii=False, indent=2)

        notes = load()
        while True:
            print("\n1. Добавить 2. Показать 3. Выход")
            choice = input("Выбор: ")
            if choice == "1":
                text = input("Текст: ")
                notes.append({"text": text})
                save(notes)
            elif choice == "2":
                for i, n in enumerate(notes, 1):
                    print(i, n["text"])
            elif choice == "3":
                break
            else:
                print("Неверный выбор")
