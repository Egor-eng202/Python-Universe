Урок 4. Арифметические и логические операторы

Теория

Арифметика: +, -, *, / (всегда float), // (целочисленное деление), % (остаток), (степень).

print(7 // 2)   # 3
        print(7 % 2)    # 1
        print(2  10)  # 1024

Сравнения: ==, !=, >, <, >=, <=. Логические: and, or, not.

Задача

Проверьте, является ли число чётным и положительным одновременно.

Подсказка
Показать решение 
n = int(input("Число: "))
        print(n % 2 == 0 and n > 0)
