Урок 13. Обработка ошибок

Теория

Исключения ловятся через try / except / finally.

try:
            x = int(input("Число: "))
            print(10 / x)
        except ValueError:
            print("Это не число")
        except ZeroDivisionError:
            print("На ноль делить нельзя")
        finally:
            print("Конец")

Частые исключения: ValueError, ZeroDivisionError, TypeError, KeyError, IndexError. Можно бросать своё: raise ValueError("...").

Задача

Запросите число и выведите его квадратный корень. Если ввели не число — сообщите об ошибке.
