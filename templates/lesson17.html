Урок 17. Стандартная библиотека

Теория

Python «из коробки» содержит мощные модули:

  • os — работа с файловой системой;
  • sys — параметры запуска, выход;
  • datetime — дата и время;
  • random — случайные числа;
  • math — математика;
  • json — сериализация;
  • re — регулярные выражения.
from datetime import datetime
        print(datetime.now())

        import os
        print(os.listdir("."))
