Урок 3. Ввод/вывод и форматирование строк

Теория

input() читает строку от пользователя, print() выводит. input() всегда возвращает str — для чисел используйте int() / float().

name = input("Ваше имя: ")
        age = int(input("Ваш возраст: "))
        print("Привет, " + name + "!")

Форматирование: f-строки — самый удобный способ:

print(f"Через год вам будет {age + 1} лет")

Задача

Запросите два целых числа и выведите их сумму в формате Сумма: X.

Подсказка

Показать решение 
a = int(input("Первое число: "))
        b = int(input("Второе число: "))
        print(f"Сумма: {a + b}")
