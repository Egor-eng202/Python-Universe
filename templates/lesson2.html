Урок 2. Переменные и базовые типы данных

Теория

Переменная — имя для значения. Создаётся присваиванием:

name = "Анна"
        age = 25
        height = 1.68
        is_student = True
  • str — строка: "Анна"
  • int — целое: 25
  • float — дробное: 1.68
  • bool — логическое: True/False
  • NoneType — отсутствие значения: None

Тип можно узнать через type(x).

Задача

Создайте переменные city (строка) и population (целое), выведите обе и их типы.

Подсказка

Показать решение 
city = "Москва"
        population = 13000000
        print(city, type(city))
        print(population, type(population))
