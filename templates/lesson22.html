Урок 22. Базы данных (SQLite)

Теория

SQLite встроен в Python. База — один файл.

import sqlite3

        conn = sqlite3.connect("test.db")
        cur = conn.cursor()

        cur.execute("""CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY,
            name TEXT
        )""")
        cur.execute("INSERT INTO users (name) VALUES (?)", ("Анна",))
        conn.commit()

        cur.execute("SELECT * FROM users")
        print(cur.fetchall())

        conn.close()

Этот сайт хранит пользователей и прогресс в SQLite — файл users.db.
