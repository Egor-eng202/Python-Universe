Урок 18. Основы ООП

Теория

Класс — шаблон для объектов. Атрибуты — данные, методы — функции.

class Dog:
            def init(self, name):
                self.name = name

            def bark(self):
                return self.name + " говорит: Гав!"

        my_dog = Dog("Рекс")
        print(my_dog.bark())

init — конструктор, self — ссылка на объект.

Задача

Создайте класс Rectangle с шириной и высотой и методом area().

Подсказка

Показать решение 
class Rectangle:
            def init(self, width, height):
                self.width = width
                self.height = height

            def area(self):
                return self.width * self.height

        r = Rectangle(4, 5)
        print(r.area())   # 20
