Урок 21. JSON и CSV

Теория

JSON — текстовый формат данных.

import json

        data = {"name": "Анна", "age": 25}
        text = json.dumps(data, ensure_ascii=False)
        print(text)

        obj = json.loads(text)
        print(obj["name"])

CSV — табличный формат.

import csv

        with open("data.csv", "w", newline="", encoding="utf-8") as f:
            writer = csv.writer(f)
            writer.writerow(["name", "age"])
            writer.writerow(["Анна", 25])

Задача

Преобразуйте список [1, 2, 3] в JSON-строку и обратно.

Подсказка

Показать решение 
import json

        s = json.dumps([1, 2, 3])
        print(s)               # "[1, 2, 3]"
        print(json.loads(s))   # [1, 2, 3]
