Урок 16. Модули и пакеты

Теория

Модуль — файл .py с кодом. Подключается через import.

import math
        print(math.sqrt(16))          # 4.0

        from random import randint
        print(randint(1, 6))

        import os
        print(os.getcwd())

Сторонние пакеты ставятся через pip install имя. Пример: pip install requests.

Свой модуль: создайте mymodule.py и импортируйте import mymodule.

Задача

Импортируйте random и выведите случайное число от 1 до 100.

Подсказка

Показать решение 
import random
        print(random.randint(1, 100))
