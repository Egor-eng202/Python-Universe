Урок 5. Условные конструкции

Теория

if выполняет код при истинном условии. elif — дополнительная проверка. else — иначе.

age = int(input("Возраст: "))
        if age >= 18:
            print("Совершеннолетний")
        elif age >= 14:
            print("Подросток")
        else:
            print("Ребёнок")

Отступы (4 пробела) обязательны — они задают блок кода.

Задача

Запросите число и выведите «Положительное», «Отрицательное» или «Ноль».

Подсказка

Показать решение 
n = int(input("Число: "))
        if n > 0:
            print("Положительное")
        elif n < 0:
            print("Отрицательное")
        else:
            print("Ноль")
