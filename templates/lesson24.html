Урок 24. Виртуальные окружения

Теория

Виртуальное окружение изолирует зависимости проекта.

python -m venv venv

        Windows:
        venv\Scripts\activate

        macOS/Linux:
        source venv/bin/activate

        pip install flask
        pip freeze > requirements.txt

Установка из файла: pip install -r requirements.txt. Выход: deactivate.

Задача

Создайте окружение, установите Flask и сохраните зависимости в файл.
