Урок 19. ООП: наследование и полиморфизм

Теория

Наследование позволяет создавать класс на основе другого.

class Animal:
            def init(self, name):
                self.name = name

            def speak(self):
                return "..."

        class Cat(Animal):
            def speak(self):
                return self.name + " говорит: Мяу"

        class Dog(Animal):
            def speak(self):
                return self.name + " говорит: Гав"

        for a in [Cat("Мурка"), Dog("Рекс")]:
            print(a.speak())

Полиморфизм — один интерфейс, разное поведение. super() вызывает метод родителя.

Задача

Создайте базовый класс Shape и наследников Circle и Square с методом area().

Подсказка

Показать решение 
import math

        class Shape:
            def area(self):
                return 0

        class Circle(Shape):
            def init(self, r):
                self.r = r
            def area(self):
                return math.pi * self.r  2

        class Square(Shape):
            def init(self, a):
                self.a = a
            def area(self):
                return self.a  2

        for s in [Circle(2), Square(3)]:
            print(round(s.area(), 2))
