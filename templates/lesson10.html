Урок 10. Функции

Теория

Функция — именованный блок кода. Объявляется через def, возвращает результат через return.

def greet(name):
    return f"Привет, {name}!"

print(greet("Анна"))

Без return функция возвращает None. Параметры могут иметь значения по умолчанию: def f(x, y=10):.

Задача

Напишите функцию square(x), возвращающую квадрат числа.

Подсказка

Показать решение 
def square(x):
    return x * x

print(square(5))   # 25
