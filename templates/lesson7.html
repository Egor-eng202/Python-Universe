Урок 7. Списки

Теория

Список — изменяемая коллекция в квадратных скобках.

fruits = ["яблоко", "банан", "вишня"]
        fruits.append("груша")     # добавить в конец
        fruits.remove("банан")     # удалить по значению
        print(fruits[0])           # яблоко
        print(fruits[-1])          # груша
        print(len(fruits))         # 3
        print(fruits[1:3])         # срез: ['вишня', 'груша']

Срезы: list[start:stop:step]. Методы: sort(), reverse(), index(), count().

Задача

Создайте список из 5 чисел, выведите его сумму, максимум и минимум.

Подсказка

Показать решение 
nums = [4, 8, 1, 9, 3]
        print("Сумма:", sum(nums))
        print("Максимум:", max(nums))
        print("Минимум:", min(nums))
