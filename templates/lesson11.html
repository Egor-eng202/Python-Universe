Урок 11. Области видимости, args и **kwargs

Теория

Переменные внутри функции — локальные, снаружи — глобальные. args принимает любое число позиционных аргументов, kwargs — именованных.

def total(*args):
            return sum(args)

        print(total(1, 2, 3))   # 6

        def info(kwargs):
            for k, v in kwargs.items():
                print(k, v)

        info(name="Анна", age=25)

Ключевое слово global позволяет менять глобальную переменную внутри функции.

Задача

Напишите функцию multiply(args), возвращающую произведение всех аргументов.

Подсказка

Показать решение 
def multiply(args):
            result = 1
            for x in args:
                result *= x
            return result

        print(multiply(2, 3, 4))   # 24
