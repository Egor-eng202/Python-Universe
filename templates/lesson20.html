Урок 20. Веб-разработка (Flask)

Теория

Flask — лёгкий веб-фреймворк. Минимальное приложение:

from flask import Flask
        app = Flask(name)

        @app.route("/")
        def index():
            return "Привет, Flask!"

        if name == "main":
            app.run(debug=True)

Шаблоны (Jinja2) рендерятся через render_template("page.html"), переменные передаются: render_template("page.html", name="Анна") и в HTML {{ name }}.

Этот сайт — тоже Flask!
