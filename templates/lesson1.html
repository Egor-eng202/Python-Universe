Урок 1. Введение в Python и среда разработки

Теория

Python — высокоуровневый язык с простым синтаксисом. Программа — это текстовый файл с расширением .py. Первая программа:

print("Привет, мир!")

print() выводит данные на экран. Текст в кавычках — строка (str).

Задача

Выведите на экран фразу Я учу Python!

Подсказка

Показать решение 
print("Я учу Python!")
