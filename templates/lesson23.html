Урок 23. Основы Git

Теория

Git — система контроля версий. Основные команды:

git init                    # создать репозиторий
        git add .                   # добавить файлы
        git commit -m "Первый коммит"
        git status                  # состояние
        git log                     # история
        git branch new-feature      # ветка
        git checkout new-feature    # переключиться

Удалённые репозитории: git remote add origin URL, git push -u origin main.
