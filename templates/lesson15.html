Урок 15. Генераторы списков и yield

Теория

Генератор списка — компактный способ создать список.

squares = [x * x for x in range(5)]
        print(squares)             # [0, 1, 4, 9, 16]

        evens = [x for x in range(10) if x % 2 == 0]

Генератор (yield) выдаёт значения по одному, экономя память.

def countdown(n):
            while n > 0:
                yield n
                n -= 1

        for x in countdown(3):
            print(x)

Задача

Создайте генератор чётных чисел от 0 до N.

Подсказка

Показать решение 
def evens(n):
            for x in range(n + 1):
                if x % 2 == 0:
                    yield x

        print(list(evens(10)))   # [0, 2, 4, 6, 8, 10]
